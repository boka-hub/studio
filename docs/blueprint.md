# **App Name**: TileForge

## Core Features:

- Import Tiles: Import individual PNG tile images.
- Spritesheet Slicer: Slice spritesheets into individual tiles using an interactive tool.
- Palette Creation: Create tile palettes from imported or sliced tiles.
- Interactive Grid: An interactive grid system for visual tile placement.
- Intelligent Tile Placement: AI Tool that infers from surrounding tiles and suggests or automatically places tiles based on patterns and consistencies in existing parts of the map.
- Map Export: Export the created map as a numerical tile index grid to a plain text file.
- Keyboard Shortcuts: Comprehensive keyboard shortcuts for all major functions.
- Drawing Tools: Drawing tools to paint tiles on the canvas, erase tiles, and pick tiles from the map.
- Undo/Redo: Up to 50 times undo and redo capabilities.
- Tile Renaming: Rename every tile in the palette.
- Tile Export: Export tiles individually or as a spritesheet.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) for interface highlights and active elements.
- Background color: Dark blue-gray (#2c3e50) for the application's base, ensuring comfortable contrast.
- Accent color: A lighter shade of light blue (#87CEEB) to provide contrast for interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look.
- Simple, outlined icons for tools and actions, in light blue.
- Clean, grid-based layout for the tile palette and map editor.
